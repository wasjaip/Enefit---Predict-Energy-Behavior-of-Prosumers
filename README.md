# Enefit — Predict Energy Behavior of Prosumers

Проект по прогнозированию энергопотребления и производства электроэнергии prosumer-клиентов в соревновании Kaggle Enefit.

## Задача

Спрогнозировать два типа целевой переменной:

- **Consumption** — потребление электроэнергии;
- **Production** — производство электроэнергии.

## Подход

Основное решение построено на ансамбле LightGBM-моделей.

Для каждой части задачи использовалось по **6 LGBM-моделей**:

- 6 моделей для Consumption;
- 6 моделей для Production.

Модели переобучались ежедневно. Для ускорения обучения использовались два GPU Kaggle T4 и параллельные процессы.

## Feature engineering

Использовались:

- стандартные календарные и категориальные признаки;
- лаги погодных прогнозов на 1–2 часа для Production;
- 7-дневные лаги температуры для Consumption;
- признаки рабочих дней;
- анализ ACF/PACF;
- продолжительность светового дня, рассчитанная по дате и широте.

## Оптимизация обучения

Для ускорения переобучения применялось выборочное использование исторических блоков данных: свежие данные сохранялись полностью, а старые периоды использовались с уменьшающейся долей.

Такой подход позволял сохранять длинную историю, не перегружая ежедневный training pipeline.

## Что тестировалось дополнительно

Проверялись, но не вошли в итоговое решение:

- смешанный ансамбль LightGBM, CatBoost и XGBoost;
- `StackingRegressor`;
- `BaggingRegressor`;
- отдельные модели по регионам.

Основной причиной отказа была стоимость инференса и ограничение времени выполнения.
